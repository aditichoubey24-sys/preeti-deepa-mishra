# Preetideepa Mishra · Portfolio

Personal portfolio of **Preetideepa Mishra**, a multidisciplinary designer working across UX/UI, brand identity, research, campaigns and product design.

**Live site:** https://preetideepamishra.github.io/preeti/

## What's inside
| File | What it does |
|---|---|
| `index.html` | All page content: hero, about, work, projects, services, contact |
| `style.css` | Colours, fonts and layout (edit the variables at the top to restyle) |
| `script.js` | Mobile menu, draggable hero cards and the case-study pop-ups (case-study text is at the top of this file) |
| `assets/img/` | Project images |

Plain HTML, CSS and JavaScript. No build step, works directly on GitHub Pages.
